# 🎣 钓鱼放置经营游戏完整策划文档（GDD）

---

# 一、游戏概述

## 1.1 游戏类型

放置经营 + 捕鱼收集 + 资源加工 + 轻策略组合

## 1.2 核心卖点

* 捕鱼 + 自动挂机双模式
* 鱼资源循环（捕鱼→养殖→加工）
* 配方生产（寿司系统）
* 鱼缸BD组合系统
* 饵料定向捕鱼策略

---

# 二、核心玩法循环

## 2.1 主循环

捕鱼 → 获得鱼 → 分流使用
→ 产业加工 → 获得金币
→ 升级系统 → 提升效率
→ 解锁地图与内容

---

## 2.2 资源循环

鱼来源：

* 捕鱼
* 养殖复制

鱼消耗：

* 产业加工
* 鱼缸配置

收益来源：

* 寿司出售（核心）
* 捕鱼（辅助）

---

## 3.1 捕鱼界面（主界面）
